# SYSTEM CONFIGURATION USER FLOW

## 1. Login

* Admin logs into the LMS
* Redirected to the Admin Dashboard

## 2. Navigate to the System Settings

* Clicks "System Configuration" or "Settings" in the sidebar.
* Lands on a configuration panel with categories such as:
  * Academic Settings
  * Roles & Permissons
  * Platform Settings
  * Notification Settings
  * Integration Settings
  * Backup & Restore

## 3. Configure Academic Settings

* Selects "Academic Settings" tab.
* Admin can:
  * Set school year start/end dates
  * Configure grading periods (e.g., 4 quarters)
  * Set grading scales (e.g., 100-75, letter grade)
  * Define track/strands offerings (e.g., STEM, ABM)
  * Enable/disable subjects per grade level
  * Set pass/fail thresholds

## 4. Manage Roles & Permissions

* Select **"Roles & Permissions"**.
* Admin can:
  * Define custom roles (e.g., Registrar, Adviser, SHS Coordinator)
  * Set module access per role (e.g., "Only registrar can view final grades")
  * Toggle permissions like:
    * Upload content
    * Approve grades
    * Access reports
    * Send announcements

## 5. Adjust platform settings

* Admin customizes system-wide preferences:
  * Timezone?
  * School logo and theme color
  * Language settings
  * Default page on login?
  * Enable/disable modules (e.g., Attendance, Chat, Forums)
