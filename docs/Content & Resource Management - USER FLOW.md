# CONTENT & RESOURCE MANAGEMENT USER FLOW

## 1. Login

* Admin logs into the LMS
* Redirected to the Admin Dashboard

## 2. Navigate to Content & Resource Management

* Admin selects **"Content & Resources"** from the sidebar
* Redirected to the Content & Resource Overview Panel, usually with tab like:
  * Lessons
  * Modules
  * Assessments
  * File/Resources
  * Curriculum Map

## 3. View Uploaded Content

* Admin can filter or search content by:
  * Grade level
  * Subject
  * Teacher
  * Track/stand (SHS)
  * Date uploaded
* Can preview content (PDF, videos, slides, etc.).

## 4. Approve or Reject Content (If moderated)

* If moderation is enabled:
  * Newly uploaded content appears under "Pending Approval".
  * Admin previews lessons or resource.
  * Can Approve, Reject, or Send Feedback to the teacher.
  * Status is updated and teacher is notified.

## 5. Organize Curriculum-Aligned Materials

* Admin can:
  * Tag uploaded lessons with curriculum codes (e.g., MELC-based)
  * Group content under **Weekly/Quarterly Units.**
  * Organize materials into structured folders by:
    * Grade level
    * Subject
    * Quarter

## 6. Upload Supplementary Materials

* Admin clicks **"Upload Resource"** or **"Add material"**.
* Uploads:
  * PDFs, docs, videos, slide decks, worksheets, links, etc.
* Tags:
  * Subject
  * Grade level
  * Week/Quarter
  * Optional: Set visibility (e.g., SHS only, advisers only)

## 7. Manage Assessments

* Admin can view assessments uploaded by teachers:
  * Quizzes
  * Summative tests
  * Performance Tasks
* Can:
  * Preview questions
  * Duplicate templates
  * Export to PDF OR LMS-native format
  * Flag questionable content

## 8. Enable or Disable Resources

* Admin can toggle resource availability:
  * Visible to teachers only
  * Visible to students
  * Archived (hidden but retained)
* Useful for phased release of content or removing outdated materials.

## 9. Monitor Usage Activity

* Admin can go to **Reports** or **Content Analytics** tab.
* View:
  * Most accessed materials
  * Most downloaded files
  * Top contributors (mga teachers)
  * Resource engagement per subject

## 10. Manage Shared Resource Library

* Admin can curate a central library of:
  * DepEd MELCs.
  * eModules
  * External links (e.g., DepEd Commons, Youtube, etc.)
* Teachers can browse and use in lesson plans.
