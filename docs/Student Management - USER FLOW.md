# STUDENT MANAGEMENT USER FLOW

## 1. Login

* Admin logs into the lms
* Redirected to the Admin Dashboard

## 2. Navigate to Student Management

* Admin clicks **"Student Managenemt"** in the sidebar or dashboard
* Lands on the **Student Management Overview Page**.

## 3. Add New Student

* Click **"Add student"**.
* Inputs:
  * Full name
  * Learner Reference Number (LRN)
  * Gender
  * Birthdate
  * Contact Info
  * Guardian Details
  * Address
  * Email (optional)
  * Upload ID or photo (optional)
* Sets:
  * Academic Year
  * Grade Level
  * Section
  * Track & Strand (for SHS)
* System creates student profile and optional LMS account (with credentials if email is added).

## 4. Enroll Students

* Admin goes to **Enrollment Management** under the Student Management.
* For each academic year:
  * View list of students eligible for enrollment
  * Selects student(a)
  * Assigns:
    * Grade level
    * Sectoin
    * Track and Strand (for SHS)
* Can enroll individually or in bulk

## 5. Assign Sections

* Admin selects a student or group > clicks "Assign Section".
* Chooses:
  * Grade level
  * Section
* Confirms and save assignments

## 6. View and Edit Student Profiles

* From the student list, admin can:
  * Search and filter by name, LRN, grade, section
  * Click on a student to view a profile
  * Edit personal and academic info.
  * Reset login credentials

## 7. Promote Students

* End of school year, admin goes to **Promotion Tab**.
* Selects:
  * Academic year
  * Grade level
* Options:
  * Promote all to next grade level
  * Manually promote individual students
  * Retain or mark as graduated (for Grade 12)

## 8. Transfer or Drop Students

* Admin selects student > clicks "Status" > chooses:
  * Transfer Out (input receiving school)
  * Dropped
  * Inactive
* System updates enrollment status and retains record history.

## 9. Bulk import Students

* Admin clicks **""Import Students"**
* Upload CSV/Excel file with multiple records
* System processes and assigns based on the data
* Displays errors for duplicates or missing fields

## 10. Monitor Student Activity

* Admin clicks on Activity logs for a student
* Can view:
  * Login history
  * Quiz/exam submissions
  * Lesson views
  * Communication activity?
  * Attendance? (if integrated)
