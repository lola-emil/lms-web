# ACADEMIC MANAGEMENT USER FLOW

## 1. LOGIN

* Admin logs into the system
* System redirects to the **Admin Dashboard**

## 2. Navigate to Academic Management

* From the dashboard, admin clicks on **"Academic Mangement"** in the sidebar or top nav.
* Lands on the **Academic Management Overview Page**.

## 3. Set Academic Year

* Admin clicks **"Add Academic Year"**.
* Inputs:
  * Start Date & End Date
  * School Year Label (e.g., SY 2025-2026)
* System saves and lists active academic years.

## 4. Manage Grade Levels

* Admin selects an academic year > clicks **"Manage Grade Levels"**.
* Can:
  * View default K-12 grade levels (Grade 7-12)
  * Add new or custom grade levels (optional)
  * Edit/remove grade level settings

## 5. Define Subjects per Grade Level

* Admin clicks "Subjects" under a grade level.
* Options:
  * Add subject (e.g., English, Math)
  * Set:
    * Subject Code
    * Semester (for SHS)
    * Unit/Hours
    * is Core/Elective
    * Prerequisites (optional)

## 6. Assign Strands & Tracks (for Grades 11-12)

* Admin opens SHS Grade Level (e.g., Grade 11)
* clicks "Manage Strands & Tracks"
* Adds strands:
  * STEM, HUMSS, ABM, TVL, etc.

## 7. Create Sections

* Navigate to **Section Management** under each grade level.
* Admin creates section (e.g., Grade 10 - Section A)
* Sets:
  * Adviser (optional)
  * Max students?
  * Assigned strands (for SHS)

## 8. Schedule Subjects

* Admin clicks "Class Schedules".
* For each section:
  * Assign subjects
  * Assign teachers
  * Set time slots and days of week
  * Avoid conflicts via schedule validation

## 9. Save  & Publish

* After setting up subjects, sections, and schedules:
  * Admin reviews summary
  * Clicks "Publish Academic Setup"
  * System notifies relevant teachers and users?
